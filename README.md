# Magma Code Usage
The program `iwahori.m` loads three primary commands; their usages are discussed below.

## Dimension Computation

The command `IwahoriDimension(p)` returns the dimension of $H^3_\text{new}(\mathcal{I}(3, p), \mathbb{C})$ (see Section 4.1). 

INPUT: `p`
* `p` - a rational prime number

OUTPUT: `p : q : r : s`
* `p` - the rational prime number input
* `q` - the dimension of $H_3(\mathcal{I}(3, p), \mathbb{C})$
* `r` - the dimension of $H^3_\text{cusp}(\mathcal{I}(3, p), \mathbb{C})$
* `s` - the dimension of $H^3_\text{new}(\mathcal{I}(3, p), \mathbb{C})$

EXAMPLE:
```C
> load "PATH/iwahori.m";
Loading "iwahori.m"
Loading "hecke_matrices.m"
> IwahoriDimension(19);
Now building matrix...
Now building the h portion of the matrix...
Now building the sigma1 portion of the matrix...
Now building the sigma2 portion of the matrix...
Now building final matrix...
Now computing dimension...
19 : 10 : 3 : 2
```

## Hecke Operator Computation

### Full Homology Space

The command `IwahoriHeckeFull(p, l_list)` returns the factorization of the characteristic polynomials $\varphi_\ell^\text{full}$ for the Hecke operators $E_\ell$ on $H_3(\mathcal{I}(3, p), \mathbb{C})$ for each $\ell$ in `l_list` as a dictionary.  The command also outputs the factorizations in the terminal throughout the computation. 

INPUT: `(p, l_list)`
* `p` - a rational prime number
* `l_list` - a list of rational prime numbers

OUTPUT: `associative array`
* `Keys` - the rational primes from `l_list`
* `Values` - the factorization of $\varphi_\ell^\text{full}$ for $E_\ell$ on $H_3(\mathcal{I}(3, p), \mathbb{C})$

EXAMPLE:
```C
> load "PATH/iwahori.m";
Loading "iwahori.m"
Loading "hecke_matrices.m"
> EDict := IwahoriHeckeFull(19, [2, 3]);
Now building the h portion of the matrix...
Now building the sigma1 portion of the matrix...
Now building the sigma2 portion of the matrix...
Now building final matrix...
Now computing the action of Hecke operator T(l, 1) for l = 2...
The factored characteristic polynomial of T(l, 1) is...
[
    <T - 7, 1>,
    <T - 4, 3>,
    <T - 1, 3>,
    <T + 2, 1>,
    <T^2 + T + 4, 1>
]
Now computing the action of Hecke operator T(l, 1) for l = 3...
The factored characteristic polynomial of T(l, 1) is...
[
    <T - 13, 1>,
    <T - 7, 3>,
    <T - 1, 1>,
    <T + 5, 3>,
    <T^2 + 4*T + 19, 1>
]
```

### Space of Previously-Unseen Forms

Using the data from `IwahoriHeckeFull(p, l_list)` combined with the results in Section 3, we can use the command `IwahoriHeckeNew(p, l_list, first_l, K, f)` to compute the characteristic polynomials $\varphi_\ell$ for the Hecke operators $E_\ell$ on $H^3_\text{new}(\mathcal{I}(3, p), \mathbb{C})$ for each $\ell$ in `l_list`.  The command returns a dictionary with values $\varphi_\ell$, as well as eigenvectors 

INPUT: `(p, l_list)`
* `p` - a rational prime number
* `l_list` - a list of rational prime numbers
* `first_l` - the first $\ell$ in `l_list`; the corresponding $\varphi_\ell$ should have non-real roots (Note, `first_l` must be the first entry in `l_list` so that the space of previously-unseen forms can be isolated) 
* `K` - the splitting field generated by the Hecke eigenvalues, i.e. the roots of $\varphi_\ell$, for several small $\ell$
* `f` - the polynomial $\varphi_\ell$ corresponding to `first_l`

OUTPUT: `associative array`
* `Keys` - the rational primes from `l_list`
* `Values` - `l : phi : v1 : e1 : v2 : e2` $\ell$ : $\varphi_\ell$ : v1 : $e_1$ : v2 : $e_2$, where $e_1, e_2$ are the Hecke eigenvalues, i.e. the roots of $\varphi_\ell$, corresponding to eigenvectors v1 and v2. 

EXAMPLE:
```C
> load "PATH/iwahori.m";
Loading "iwahori.m"
Loading "hecke_matrices.m"
> EDict := IwahoriHeckeNew(19, [2, 3, 5], 2, NumberField(T^2 - T + 4), T^2 + T + 4);
Now building the h portion of the matrix...
Now building the sigma1 portion of the matrix...
Now building the sigma2 portion of the matrix...
Now building final matrix...
Now computing the action of Hecke operator T(l, 1) for l = 2...
2 : T^2 + T + 4 : v1 : -w : v2 : w - 1
Now computing the action of Hecke operator T(l, 1) for l = 3...
3 : T^2 + 4*T + 19 : v1 : 2*w - 3 : v2 : -2*w - 1
Now computing the action of Hecke operator T(l, 1) for l = 5...
5 : T^2 - 2*T + 16 : v1 : 2*w : v2 : -2*w + 2
> EDict[3];
3 : T^2 + 4*T + 19 : v1 : 2*w - 3 : v2 : -2*w - 1
```
